# ProjetoIAA2

Rotina: git pull origin main -> Puxa as novidades do Github para o VS git add . -> Prepara todos os ficheiros que alteras ou apagas git commit -m "Mensagem de alteração" -> Grava alterações localmente com uma nota git push origin main -> Envia tudo gravado para o Github

Diagnostico: git status -> Mostra alterações feitas em ficheiros git branch -> Mostra a ramificação git log --oneline -> Histórico recente de commits

Emergência: git push origin main --force git merge --abort git reset --hard HEAD
